Do's y Don'ts

✓ Sí

  • Usar azul para acciones primarias y navegación activa.
  • Usar verde para énfasis de apoyo.
  • Mostrar estados con texto e icono además del color.
  • Mantener el foco de teclado visible y los controles táctiles amplios.

✗ Evitar

  • Usar texto blanco sobre el verde de marca.
  • Recargar las fotos con etiquetas decorativas.
  • Ocultar acciones importantes solo al pasar el cursor.
  • Permitir desplazamiento horizontal de toda la página en móvil.
